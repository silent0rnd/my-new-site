# Правила работы с проектом

## Изменения
- Выполняй только задачу пользователя. Не делай несвязанных правок, рефакторингов и «улучшений».
- Не удаляй и не отключай существующие файлы, контент, функции, HTML-блоки, CSS-стили, скрипты, анимации, обработчики событий и зависимости без прямого указания пользователя.
- Перед правкой изучи изменяемый файл и только те связанные файлы, которые нужны для задачи. Фактический код важнее документации.

## Навигация и экономия контекста
- Сначала используй пути из задачи. Если непонятно, где расположен нужный файл, открой соответствующий раздел `project-map.md`.
- Ограничивай поиск нужным каталогом. Не сканируй весь проект и не выводи большие списки файлов или полное содержимое объёмных файлов без необходимости.
- Для статей: `blog/<slug>/index.html` — страница статьи, `blog/index.html` — архив; генератор — `scripts/generate-blog-archive.js`, оптимизация изображений — `scripts/optimize-blog-images.js`. Обращайся к генераторам, только если затронута их область работы.
- Запускай только относящиеся к задаче команды сборки и проверки из `package.json`. Не выполняй общие проверки без необходимости.
- Не создавай и не обновляй общий индекс файлов проекта.

## Отчёт
- В конце кратко перечисли **все** созданные и изменённые файлы и результаты проверок.
- Отдельно перечисли все удаления. Если их не было, напиши: `Удалено: ничего`.
