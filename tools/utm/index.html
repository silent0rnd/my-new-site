Генератор UTM-меток

Заполняете поля слева — готовая ссылка сразу видна справа. Все считается в браузере, ничего никуда не отправляется.

1. Соберите метку

Поля можно писать по-русски. Как только перейдете в другое поле, буквы станут английскими, а пробелы — дефисом.

2. Готовая ссылка

Что придет в отчет

Строка отчета Что стоит в метке

Пример ссылки после клика — числа здесь выдуманы

3. Размножьте метку на все объявления

Ссылка одна, а каналов или объявлений двадцать. Чтобы потом разобрать отчет, метки должны отличаться. Впишите список в то поле, которое меняется. Можно списком строк, можно номерами. Список можно вставить прямо из таблицы — строками, через запятую или через табуляцию. Русские названия сами станут английскими.

Меняется utm_source — канал

Меняется utm_campaign

Меняется utm_content

Без галочки значения идут парами: первая строка одного списка встает в один ряд с первой строкой другого. С галочкой каждое значение соединяется с каждым: 20 каналов и 3 объявления дадут 60 ссылок.

4. Пакет ссылок

Обратная задача: адресов много, метка одна. Вставьте список адресов, по одному в строке.

Как этим пользоваться в работе

Разметку стоит завести один раз и держать одинаковой во всех кампаниях. Иначе один источник разъедется в отчетах на несколько строк, и сравнивать будет нечего.

Кнопка «Ссылка на этот шаблон» кладет все настройки прямо в адрес страницы. Такую ссылку можно отправить подрядчику или коллеге: у него откроются те же поля. Кнопка «Поделиться сервисом» наверху копирует чистый адрес инструмента, без ваших настроек.
