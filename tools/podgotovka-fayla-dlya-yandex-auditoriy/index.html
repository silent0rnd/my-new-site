Подготовка файла для Яндекс Аудиторий

Очистите телефоны и email, удалите дубли и скачайте готовый CSV для загрузки в Яндекс Аудитории.

Все данные обрабатываются только в вашем браузере. Файл не загружается на сервер и нигде не сохраняется.

Загрузите файл с данными

Выберите CSV, XLSX или TXTПеретащите файл сюда или выберите его на компьютере
Вставить данные из таблицы вместо файла

Если включите хеширование, при загрузке в Яндекс Аудитории выберите SHA-256.

Результат обработки

Для создания сегмента Яндекс Аудиторий требуется не менее 100 записей.
