Лиды по $4 для фабрики детской одежды (кейс Яндекс Директ для производства в Кыргызстане)

Коротко о проекте

  • ниша: производство детской одежды

  • регион производства: Кыргызстан

  • направления:

    • пошив детской одежды на заказ оптом

    • продажа готовой продукции оптом

  • источник трафика: Яндекс Директ

  • рекламный бюджет: ≈ $500 в месяц

У фабрики ограниченные производственные мощности, поэтому задача рекламы - привлекать стабильный поток B2B-заявок без перегрузки производства.

Структура продвижения

Для проекта были сделаны два отдельных лендинга:

1️⃣ пошив одежды на заказ
2️⃣ продажа готовой продукции оптом

Изначально клиент хотел вести трафик на многостраничный сайт, но от этой идеи удалось отказаться.

Для рекламы лендинги почти всегда конвертят лучше, потому что:

  • пользователь получает одно конкретное предложение

  • нет лишней навигации

  • проще управлять конверсией.

Результаты рекламы

РСЯ (основной источник лидов)

Большая часть заявок приходит именно из сетей.

Удалось выйти на ≈ $4 за лид. Это основной рабочий канал для проекта.

Поиск - пошив одежды

Поисковая кампания на услуги производства также показала хорошие результаты ≈ $13 за лид. Это качественные заявки от предпринимателей, которые ищут фабрику для пошива.

Поиск - готовая продукция

Самой дорогой оказалась кампания на продажу готовой продукции со склада.

Стоимость лида ≈ $40

При этом трафик был максимально чистым:

  • оптимизация практически каждый день.

  • регулярная чистка минус-слов

  • фильтрация нерелевантных запросов

Используемые инструменты

В проекте использовался широкий набор инструментов Яндекс Директа:

  • поисковые кампании

  • РСЯ

  • мастер-кампании

  • кампании по конкурентам
    (российские, белорусские и фабрики из Средней Азии)

  • LAL-аудитории
    на основе базы клиентов.

Использование квиза

В качестве формы заявки был выбран квиз на Markquiz.

Это решение дает несколько преимуществ:

  • повышает конверсию лендинга

  • позволяет получать микроконверсии

  • помогает обучать алгоритмы РСЯ.

Благодаря этому кампании быстрее находят аудиторию, склонную к заявке.

Потенциал дальнейшей оптимизации

Поисковая кампания на готовую продукцию пока остаётся самой дорогой.

Планируется:

  • перевести её на оптимизацию по микроконверсии

  • обучить алгоритмы на промежуточных действиях пользователей.

Есть высокая вероятность снизить стоимость заявки до ≈ $15 за лид

Итог

Рекламные кампании позволили получить стабильный поток B2B-заявок при небольшом бюджете:

  • $4 за лид из РСЯ

  • $13 за лид по пошиву одежды

  • $40 за лид по готовой продукции из поиска

Основная часть заявок приходит из рекламных сетей, что является типичной ситуацией для B2B-производства.
