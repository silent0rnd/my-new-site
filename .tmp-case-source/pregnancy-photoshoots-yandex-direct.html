31 июля 2021

Заявки по 162 руб. на фотосессии для беременных в Санкт-Петербурге (кейс Яндекс Директ)

Коротко о проекте

  • ниша: фотосессии для беременных

  • регион: Санкт-Петербург

  • источник трафика: Яндекс Директ

  • период работы: 2 месяца

Задача - получать заявки на фотосессию по минимальной цене при небольшом рекламном бюджете.

Результаты рекламы

За два месяца работы получили следующие показатели:

  • расход бюджета - 6 000 руб.

  • средняя стоимость клика - 34,88 руб.

  • стоимость заявки - 162 руб.

  • конверсия сайта - 21,5%

Для услуг в сфере фотосессий это очень высокий показатель конверсии.

Особенность сайта

Лендинг имел только один способ оставить заявку - написать в WhatsApp.

Именно переход в WhatsApp использовался как основная цель для отслеживания конверсий. Это создавало важное ограничение.

Решение по трафику

Так как:

  • не у всех пользователей на компьютере установлен WhatsApp

  • на ПК люди реже пишут в мессенджеры

Было принято решение отключить трафик с десктопных устройств и оставить только мобильный трафик. Это позволило направлять пользователей сразу в привычный канал коммуникации.

Особенность рекламных кампаний

Из-за этой стратегии результаты по типам кампаний сильно отличались.

Поиск

  • показал лучшие результаты

  • давал наиболее целевой трафик

  • обеспечил основную часть заявок.

РСЯ

  • отработала значительно хуже

  • мобильный трафик из сетей часто менее качественный

  • часть кликов приходилась на нерелевантные площадки.

Рекомендации для дальнейшего роста

Чтобы увеличить количество заявок, было предложено:

  • создать отдельный лендинг для десктопного трафика, где можно оставить заявку через:

  • форму обратной связи

  • кнопку заказа звонка.

Это позволит:

  • вернуть десктопный трафик

  • увеличить общий объем заявок

  • не ограничивать пользователей только WhatsApp.

Итог

За два месяца рекламных кампаний удалось получить:

  • стоимость заявки - 162 руб.

  • конверсию - 21,5%

  • 6000 руб. рекламного бюджета

Основной поток заявок обеспечили поисковые кампании, ориентированные на мобильную аудиторию.
