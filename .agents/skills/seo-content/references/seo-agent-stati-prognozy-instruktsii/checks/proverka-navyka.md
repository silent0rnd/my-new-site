# Проверка интеграции SEO-навыков (без публикации)

## 1. Маршрутизация

- Тема «Как изменить объект продвижения в Яндекс Директе» -> `STANDARD`.
- Тема «Продвижение установки кондиционеров: бюджет, стоимость лида и прогноз» -> `FORECAST`, с дополнительной инструкцией v17.
- Содержательная классификация не зависит от того, употреблено ли слово «прогноз» в заголовке.

## 2. Этапы и остановки

- Первая команда с новой темой возвращает SEO-анализ, H2/H3, количество иллюстраций и все IMAGE-SPECS, **без полного ARTICLE-BODY, без изображений и ZIP**.
- «Делай первую» запускает строго одно изображение №1, с учётом дизайн-системы и проверки JPG. Нет несанкционированной генерации №2.
- «Дальше» при готовой №1 и невыполненной №2 означает №2, а не текст.
- После принятия N/N и «пиши статью» выдаются SEO-META и ARTICLE-BODY; картинки не перегенерируются.
- Итоговый архив собирается только по явной команде об архиве.
- Невозможность реальной генерации/конвертации не выдаётся за успех.

## 3. Проверки содержания

- Для FORECAST разделены опубликованные показатели, пересчитанная арифметика и прогноз с явными допущениями.
- По возможности использованы кейсы РФ за 6 месяцев (расширение до 12 только по нехватке).
- Из одного кейса не создана выдуманная «средняя цена лида»; CPC, CPL, CPA/CAC и конверсии рассчитываются корректно.
- Никакие отзывы, данные, цены, личные результаты автора или URL не сочинены.
- Интент, каннибализация и уместная внутренняя перелинковка проверены; старые URL не изменены без причины.
- На картинках и в статье одинаковые подписи, цифры, выводы и сценарии. Внутри ARTICLE-BODY нет IMAGE-SPECS.

## 4. Изображения и файл

- При наличии генератора проверка одной отдельной картинки: диорама, светлый почти белый фон, читаемые русские подписи, не менее 7 смысловых компонентов, 3 плана, смысловые связи.
- Только JPG 2896 x 2172 px, 4:3, качество 93%; без полей, искажения и обрезки; имена латиница + строчные + дефисы.
- В ZIP только окончательные утверждённые JPG, статья UTF-8 и ТЗ с точными H2, местами и alt.

## 5. Регрессия

- После интеграции исходные возможности `seo-content`, `seo-content-brief`, `seo-page`, `seo-optimizer`, `blog` сохранены.
- Текущий сайт и опубликованные файлы не изменены в ходе настройки.
- Все ссылки на поставляемые инструкции внутри навыков разрешаются в реальные файлы.
