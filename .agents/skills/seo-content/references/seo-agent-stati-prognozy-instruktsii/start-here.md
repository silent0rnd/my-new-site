# Пакет правил статей naklikay.ru для агента

Назначение: дополнить **существующие**, а не заменить навыки `seo-content`, `seo-content-brief`, `seo-page`, `seo-optimizer` и `blog`, чтобы агент мог готовить статьи-инструкции (STANDARD) и статьи с рекламным прогнозом (FORECAST) по методике проекта SEO.

## Что делать

1. Открыть `agent-task.md` и выполнить его как рабочее задание по интеграции в локальный проект агента.
2. Сохранить существующие возможности и разделение ответственности пяти навыков. Прежде чем менять файлы, выяснить их фактическое расположение и правила запуска.
3. Подключить `instructions/00-poryadok-raboty.md` как главный порядок этапов. Нюансы FORECAST - из `instructions/instruktsiya-statya-prognoz-v17.md`, с учётом точечных переопределений в `instructions/05-sovmestimost-prognoza.md`.
4. Остальные инструкции и `references/sitemap.xml` использовать как справочные материалы навыка; проверить по `checks/proverka-navyka.md`.

## Важно

- Исходные файлы пользователя в архиве не изменены. Инструкция FORECAST v17 оставлена оригинальной; устаревшие ссылки и порядок из неё переопределены отдельным файлом совместимости.
- `sitemap.xml` - снимок на момент подготовки архива, не замена проверки текущих файлов сайта и работающих URL.
- Архив не содержит написанных статей или изображений. Это пакет настройки агента, не команда создавать или публиковать материал.
- До прямой команды пользователя не редактировать действующие страницы и не запускать публикацию.
