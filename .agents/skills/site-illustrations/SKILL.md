# Иллюстрации сайта

## Обязательные материалы

Перед планированием, генерацией или перерисовкой иллюстрации полностью прочитать:

- references/03-dizayn-sistema-chatgpt.md
- references/04-instruktsiya-generatsii-illyustratsiy.md

Считать эти файлы единственными актуальными источниками требований к визуальному языку, композиции, читаемости, проверке, формату и экспорту. Не заменять их кратким пересказом или правилами из памяти.

## Порядок применения

1. Определить, относится ли задача к новой иллюстрации, перерисовке, замене, экспорту или подключению уже утверждённого изображения.
2. Для новой иллюстрации или перерисовки применить оба обязательных материала полностью.
3. Для технического экспорта или подключения утверждённого изображения не оценивать его заново и не менять композицию. Выполнить только запрошенную обработку и требования интеграции.
4. Для статьи одновременно использовать навык blog и его сценарий редактирования или создания.
5. Для кейса сохранить действующий контракт данных, подписи, alt, метаданные, имя файла и место подключения.
6. При конфликте соблюдать прямой запрос пользователя, утверждённый IMAGE-SPEC, материалы этого навыка и проектные правила в указанном порядке.
7. После получения новой версии документа заменить соответствующий файл в references без создания параллельных копий.
