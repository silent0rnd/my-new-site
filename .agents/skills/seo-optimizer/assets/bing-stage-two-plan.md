# Техническое задание Codex на второй этап

Запускать только по новой команде пользователя после установки навыка.

1. Найти реальный Webvisor: исходники, Apps Script/другой runtime, расписания,
   листы Google-таблиц, структуру данных Google и Яндекса, конфиги.
2. Составить детальный план безопасного добавления Bing Search: официальный
   API, подтверждённые методы, доступные значения и гранулярность,
   авторизация через секреты и тестовая property.
3. Отдельно проверить официальный способ выгрузки Bing AI Performance:
   если нет поддерживаемого API/экспорта, статус `manual / unavailable`.
4. Сохранить бэкап и тесты, разработать изолированный адаптер, провести
   теневой сбор, сравнить с кабинетом и показать результат.
5. Не выполнять изменение скриптов, расписаний, production или Google-таблиц
   без явного согласования конкретного плана и diff.
