# Bing Webmaster Tools: отдельный SEO-источник

Актуальность требований проверить по Microsoft Learn и Bing Webmaster Blog
перед реализацией: интерфейс и API могут меняться.

## Что известно на 14.11.2026

- В Bing Webmaster Tools есть данные обычного поиска: поисковые запросы,
  статистика трафика/ранжирования, техническое состояние, ссылки и обход.
- Официальный Bing Webmaster API позволяет получать часть статистики и данных
  сайта. Использовать актуальный **REST API**; старые SOAP/POX прекращены в 2026.
- AI Performance (публичное предварительное представление с 10.02.2026)
  показывает цитирование URL в поддерживаемых Microsoft AI-поверхностях,
  включая Copilot, AI-ответы Bing и некоторые партнёрские интеграции.
- Topics Portfolio (beta, 13.10.2026) показывает тематики и возможности в
  поддерживаемых AI-ответах, если для сайта хватает данных.
- Наличие отчёта в интерфейсе НЕ означает наличия публичного API ко всем
  метрикам AI Performance. До подключения проверить официальную документацию
  и наличие штатного экспорта для конкретного аккаунта.

## Основные понятия и метрики

**Bing Search Performance:** клики, показы, CTR, позиция/другие атрибуты
ровно в объёме, который API фактически отдаёт. Сохранять оригинальные поля
и значения. Не выдумывать отсутствующую привязку `query + page + day`.

**Bing AI Performance:** citations / cited pages / grounding queries и
тематики, **только если метрика действительно доступна в кабинете или
подтверждённом экспорте**. Указывать границы покрытия; цитирование не равно
клику, показу органической выдачи, позиции, визиту или продаже.

**Индексация:** данные обхода, доступности, sitemaps и другие технические
сигналы имеют собственную задержку; «не проиндексировано» не выводится
из нулевого числа кликов.

## Порядок ручной первичной проверки

1. Открыть Bing Webmaster Tools и проверить право владения **именно**
   `https://naklikay.ru/`, выбранную property, sitemap, регион/страницы.
2. Убедиться в доступности Search Performance и выбрать даты с полным окном.
3. Проверить, есть ли AI Performance, какие колонки доступны, какой период,
   есть ли официальный экспорт и не скрыта ли вкладка из-за малого объёма.
4. Сравнить несколько реальных URL с sitemap и текущим сайтом.
5. Составить реестр доступных полей, даты последней записи, пределы истории,
   размер выборки, гранулярность и ограничения; только после этого писать парсер.
6. Секреты (API key/OAuth и т.п.) передавать только в защищённые настройки
   среды/хранилище секретов. Никогда не вставлять в чат, архив, Git или отчёт.

## Что не делать

- Не объединять CTR/позиции Яндекс, GSC и Bing математически.
- Не представлять число citations как долю всех нейросетей или видимость ChatGPT.
- Не пытаться автоматизировать недокументированный личный интерфейс
  через ненадёжный скрейпинг/обход авторизации.
- Не пытаться отправлять IndexNow или URL submission без отдельной задачи.
- Не добавлять новый лист Google-таблицы, пока не проверены её схема и
  возможность безопасно расширить существующий мониторинг.
