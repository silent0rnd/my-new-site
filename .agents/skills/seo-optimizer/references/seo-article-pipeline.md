# Конвейер статей naklikay.ru и граница с blog

Описанный порядок действует для доработки опубликованных статей, когда
пользователь начинает тему/даёт исходник и не просит немедленного финального
результата. Прямое конкретное задание пользователя на готовые тексты/файлы
приоритетнее очередности по умолчанию. Нельзя выдавать финальный текст и
публиковать без задания пользователя.

## Этап 1. SEO-анализ и план

Прочитать весь исходный HTML/MD, Title/Description/H1, ссылки, таблицы,
существующие изображения, кейсы; сравнить с индексом/сайт-картой, свежими
показателями, интентом, текущими официальными требованиями и SERP.
Кратко дать: что сохранить/усилить/добавить/сократить, риски каннибализации,
структуру H2/H3, факты и числа с основаниями.

Для статьи с необходимостью иллюстраций указать `Иллюстраций: N` (обычно 3,
по смыслу 4-6) и все `IMAGE-SPEC-N`: тема, точный H2/место, одна главная
мысль, выбранный визуальный тип, объекты и их связи/результат, ракурс,
3+ дополнительных смысловых элемента, крупные русские подписи и
подтверждённые числа, Alt. Не добавлять картинки ради декора. Остановиться.

## Этап 2. Иллюстрации

Одна утверждаемая картинка по одной команде; не генерировать весь комплект
самовольно. Референсы, композиция и экспорт 4:3 JPG 2896 x 2172,
качество 93% определяются дизайн-системой. Только `IMAGE-SPEC-N` и
применимые правила визуализации. После каждой остановиться. Если у агента
нет поддерживаемого генератора, только подготовить IMAGE-SPECS и не
утверждать, что иллюстрации созданы.

## Этап 3. Текст

Когда картинки согласованы и пользователь запросил статью: `SEO-META`,
полный `ARTICLE-BODY`, точное ТЗ публикации с H2/Alt/именами.
Для коммерческих страниц сохранять релевантные кейсы, стоимость только
подтверждённую, личную роль автора и CTA. Исключать повторы, выдуманные
данные, ошибочные расчёты и нейрошаблоны. Не менять ранее утверждённые
изображения под новый текст; все цифры согласовать.

## Этап 4. ZIP/публикация

По отдельной просьбе: последняя согласованная статья, только утверждённые
JPG, точные места вставки, без PNG и черновиков, UTF-8; имена латиницей,
нижний регистр, дефисы. За публикацию и техническую сборку сайта отвечает
действующий `blog`; `seo-optimizer` передаёт дифф/ТЗ. Самовольно не
публиковать и не запускать переобход.

## Редакторские источники в комплекте

Точные рабочие инструкции находятся в `references/source-instructions/`:
`instruktsiya-dlya-seo-statey.md`, `instruktsiya-statya-prognoz.md`,
`dizayn-sistema-illyustratsiy.md`, `instruktsiya-generatsii-illyustratsiy.md`.
Они предоставлены для контекста и не заменяют более новые подтверждённые
инструкции `blog` в живом репозитории. Для типа FORECAST дополнительно
применять `instruktsiya-statya-prognoz.md`.
