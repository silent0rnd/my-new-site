URL: https://docs.google.com/spreadsheets/d/1ki2ik3KrdEvWwU21ogK02Fc5nBQECap09rgbyN_w-Fo/edit

Назначение: основной фактический источник для регулярного аудита существующих страниц naklikay.ru.

Обязательные листы:

- Фразы
- Архив целевых фраз
- SEO-сводка
- Настройки
- Группы
- Запросы
- Страницы
- Проблемы
- Недельная история
- URL-запросы PRO
- История страниц
- Журнал усилений
- PRO-покрытие
- Запросы по страницам
- Метрика
- Цели Метрики

Правила использования:

- Перед выводами проверять фактический период данных, а не только время запуска скрипта.
- Сначала сверять URL с «Журналом усилений».
- Использовать 7 дней как быстрый сигнал, 28 дней как основное окно и 90 дней как устойчивый контекст.
- Основная фраза на листе «Фразы» является контрольной, а не полным семантическим ядром.
- Для выводов по странице использовать реальные запросы из листов «Запросы» и «Запросы по страницам».
- Не изменять таблицу без прямой команды пользователя.
- Не создавать лист «Кластеры».
- Не искать и не назначать новые статьи.
