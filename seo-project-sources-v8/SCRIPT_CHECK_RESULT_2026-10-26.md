# Результат проверки Apps Script

Проверен действующий проект «SEO мониторинг» по адресу:
https://script.google.com/u/0/home/projects/1bckLikR0LsVwqsNSqhlym36J9Rpz8_CrYq6Damb33UtK2-JvVPgxfISa/edit

## Решение

Скрипт менять не нужно.

## Что уже работает

- Основной код v3.11 обновляет данные Яндекс Вебмастера.
- Собираются группы, запросы, страницы, проблемы и недельная история.
- Ведется история страниц для окон 28 и 90 дней.
- PRO собирает запросы по URL, покрытие и накопительную 28-дневную историю.
- Ошибка PRO не блокирует основной SEO-отчет.
- После готовности PRO отчет пересчитывается автоматически.
- Модуль Метрики v4 сравнивает последние 28 дней с предыдущими 28 днями и добавляет контекст 90 дней.
- Токены хранятся в Script Properties.

## Почему текущая ошибка не требует правки

Используемый адрес /v4/user/{user-id}/hosts/{host-id}/pro/serp/dates соответствует официальной документации Яндекс Вебмастера. Недоступность этого адреса относится к состоянию сервиса, а не к ошибке маршрута в коде.

Основной сбор 26.10.2026 завершился успешно. Отдельно нужно смотреть фактическую конечную дату данных, потому что успешный запуск не гарантирует свежесть данных на стороне Яндекса.
