Цели для Марквиза в Метрике: идентификаторы Marquiz

24 августа 2026·Максим Мирошников

Если на сайте установлен квиз Marquiz, в Яндекс Метрике можно отслеживать не только отправленные заявки, но и прохождение отдельных этапов квиза. Например, запуск квиза, переход к первому или второму вопросу, открытие формы контактов и успешное завершение.

Для этого в Метрике создаются цели с идентификаторами событий, которые передает Marquiz.

Основные цели Marquiz для Яндекс Метрики

Для большинства квизов достаточно следующих целей:

Название цели в МетрикеИдентификатор
Автоцель Marquiz: запуск квизаmarquiz-start
Квиз - вопрос 1marquiz-step1
Квиз - вопрос 2marquiz-step2
Квиз - вопрос 3marquiz-step3
Квиз - дошёл до формы контактовmarquiz-form
Квиз - Страница «Спасибо»marquiz-finish

Если в квизе больше вопросов, используется тот же принцип:

marquiz-step4 - пользователь прошёл четвёртый вопрос.

marquiz-step5 - пользователь прошёл пятый вопрос.

И так далее.

То есть вместо создания одной цели только на отправку заявки можно отслеживать практически всю воронку прохождения квиза.

Как настроить цели Marquiz в Метрике

Откройте нужный счётчик Яндекс Метрики и перейдите в раздел «Цели».

Нажмите «Добавить цель».

Выберите тип цели «JavaScript-событие».

В качестве идентификатора укажите:

marquiz-form

Сохраните цель.

Например, для отслеживания первого вопроса можно создать цель:

Название: Квиз - вопрос 1
Идентификатор: marquiz-step1

Для страницы благодарности:

Название: Квиз - Страница «Спасибо»
Идентификатор: marquiz-finish

Само название цели может быть любым. Главное, чтобы идентификатор события был указан правильно.

Какие цели Marquiz я обычно настраиваю

Я обычно не ограничиваюсь только финальной отправкой формы. Для анализа рекламы удобнее видеть основные этапы прохождения квиза:

  1. marquiz-start - человек запустил квиз.
  2. marquiz-step1 - прошёл первый вопрос.
  3. marquiz-step2 - прошёл второй вопрос.
  4. marquiz-step3 - прошёл третий вопрос.
  5. marquiz-form - дошёл до формы с контактными данными.
  6. marquiz-finish - завершил квиз и дошёл до финального этапа.

Количество целей marquiz-stepN зависит от количества вопросов в конкретном квизе.

Если вопросов семь, при необходимости можно создать цели от marquiz-step1 до marquiz-step7.

Зачем отслеживать прохождение вопросов

Отслеживание целей позволяет увидеть, на каком этапе пользователь прекращает прохождение квиза.

Например:

  • квиз открыли 1000 человек;
  • до первого вопроса дошли 800;
  • до формы контактов дошли 200;
  • заявку отправили 120.

Если много людей запускают квиз, но не доходят до первого вопроса, возможно, проблема в первом экране или формулировке оффера.

Если пользователи проходят несколько вопросов, но не доходят до формы контактов, стоит посмотреть на структуру квиза, сложность вопросов и количество шагов.

Если люди доходят до формы, но не отправляют заявку, возможно, форма слишком длинная или вызывает недоверие.

Без промежуточных целей в Метрике будет видно только количество запусков и заявок. Причину низкой конверсии определить будет сложнее.

Какая цель Marquiz считается заявкой

Для оценки реальных заявок в первую очередь нужно смотреть на финальное событие:

marquiz-finish

Оно фиксирует завершение квиза после отправки контактных данных или прохождения предусмотренного финального сценария.

При этом marquiz-form не означает, что заявка уже отправлена. Эта цель показывает, что пользователь дошёл до формы контактов.

Поэтому эти две цели лучше не смешивать:

marquiz-form - дошёл до формы.

marquiz-finish - завершил квиз.

Так можно отдельно оценить конверсию из просмотра формы контактов в её отправку.

Какие цели использовать для рекламы

Для оптимизации рекламных кампаний не стоит без необходимости использовать каждый вопрос квиза как полноценную конверсию.

marquiz-step1, marquiz-step2 и другие промежуточные события полезны прежде всего для аналитики.

Основной целью для оценки качества рекламы обычно будет marquiz-finish.

Дополнительно можно анализировать:

  • marquiz-start - сколько пользователей действительно начали проходить квиз;
  • marquiz-form - сколько пользователей дошли до этапа ввода контактов;
  • marquiz-finish - сколько пользователей завершили квиз.

Так получается простая воронка:

переход на сайт → запуск квиза → прохождение вопросов → форма контактов → заявка.

Как проверить, работают ли цели Marquiz

После настройки целей откройте сайт и самостоятельно пройдите квиз.

  1. Запустите квиз.
  2. Пройдите несколько вопросов.
  3. Дойдите до формы контактов.
  4. Отправьте тестовую заявку.
  5. Проверьте достижение целей в Яндекс Метрике.

Если всё настроено правильно, Метрика должна зафиксировать соответствующие события.

Особенно важно проверить marquiz-finish, поскольку именно эта цель обычно используется как основная конверсия для рекламных кампаний.

Подробнее о проверке события после настройки - в статье «Как проверить цель в Яндекс Метрике».

Частые вопросы

Какой идентификатор цели отвечает за запуск Marquiz?

Для запуска квиза используется:

marquiz-start

Как настроить цель на первый вопрос Marquiz?

Используйте идентификатор:

marquiz-step1

Для второго вопроса - marquiz-step2, для третьего - marquiz-step3 и далее по аналогии.

Какая цель показывает, что пользователь дошёл до формы контактов?

Используйте:

marquiz-form

Она показывает переход к форме сбора контактных данных, но ещё не означает успешную отправку заявки.

Какая цель Marquiz отвечает за завершение квиза?

Для финального этапа используется:

marquiz-finish

Именно эту цель обычно имеет смысл использовать как основную конверсию при оценке заявок из квиза.

Нужно ли создавать цели на каждый вопрос?

Не обязательно. Если требуется только считать заявки, достаточно основных целей. Промежуточные marquiz-stepN полезны, когда нужно анализировать воронку и находить вопросы, на которых пользователи чаще всего прекращают прохождение квиза.

Итог

Базовый набор целей Marquiz в Яндекс Метрике выглядит так:

marquiz-start - запуск квиза
marquiz-step1 - первый вопрос
marquiz-step2 - второй вопрос
marquiz-step3 - третий вопрос
marquiz-form - переход к форме контактов
marquiz-finish - завершение квиза

Для анализа рекламы наиболее важны marquiz-start, marquiz-form и marquiz-finish. Цели marquiz-stepN позволяют дополнительно посмотреть прохождение каждого вопроса и понять, на каком этапе квиз теряет пользователей.
