# Дизайн-система инфографики для статей

Источник стиля - иллюстрации статьи «Продвижение рекламного производства». Этот документ - единый визуальный код для всех новых схем, карточек и инфографики в блоге naklikay.ru.

## 1. Характер стиля

Инфографика должна выглядеть как ясное объяснение бизнес-процесса, а не как рекламный баннер. Основа - почти белое поле, крупный графитовый заголовок, одна оранжевая акцентная линия и предметные 3D-иконки на белых карточках.

Ключевые признаки:

- чистая редакционная композиция с большим количеством воздуха;
- только один активный цвет - оранжевый;
- крупные, тяжелые заголовки без декоративных шрифтов;
- белые карточки со скруглением и очень мягкой тенью;
- простые 3D-объекты с матовой поверхностью, без фотореализма;
- одна понятная мысль на одну иллюстрацию;
- симметрия допустима для сравнений и цепочек, но не должна превращать изображение в шаблонную сетку;
- никаких логотипов, водяных знаков, мелкого текста или декоративного шума.

## 2. Палитра

| Роль | Значение | Использование |
|---|---:|---|
| Фон инфографики | `#FAFAF8` | Весь холст |
| Поверхность карточки | `#FFFFFF` | Карточки, плашки, подложки |
| Основной текст | `#171B20` | Заголовки, цифры, контуры объектов |
| Вторичный текст | `#30343A` | Подписи, пояснения |
| Приглушенный текст | `#6D7177` | Только второстепенные строки |
| Оранжевый акцент | `#FF6A00` | Стрелки, ключевые числа, маркеры, отдельные детали иконок |
| Темный оранжевый | `#D95400` | Глубокие грани оранжевых 3D-объектов |
| Светлый оранжевый | `#FFF0E5` | Только очень слабая подсветка, не основной фон |
| Светлая граница | `#ECEDEA` | Если край карточки теряется на белом |
| Тень | `rgba(23, 27, 32, 0.10)` | Мягкая тень под карточками и объектами |

Правила цвета:

- доля оранжевого на одном холсте - до 12% площади;
- текст заголовков и обычных подписей - только графитовый, не оранжевый;
- белый используется как материал карточек, а не как самостоятельный контрастный блок;
- не добавлять синий, фиолетовый, зеленый, градиентный фон или второй акцентный цвет;
- оранжевый допустим для одного главного числа в сравнении и для направления движения в схеме.

## 3. Холст и безопасная зона

| Параметр | Значение |
|---|---:|
| Основное соотношение | `4:3` |
| Рабочий размер | `2896 × 2172 px` |
| Минимум для новой инфографики | `1536 × 1152 px` |
| Внешние поля | `160 px` слева и справа, `120 px` сверху и снизу при размере 2896 × 2172 |
| Межкарточный отступ | `52-72 px` |
| Скругление карточек | `56 px` |
| Скругление малых плашек | `32 px` |
| Тень карточки | `0 18px 42px rgba(23, 27, 32, 0.10)` |
| Тень 3D-объекта | `0 20px 26px rgba(23, 27, 32, 0.15)` |

Инфографика всегда экспортируется без рамки и без отдельных полей вокруг изображения. Белое пространство внутри холста - часть композиции.

## 4. Типографика

Для инфографики используется локальная гарнитура сайта `TT Masters`. Если генератор не умеет воспроизводить её буквально, ориентир - нейтральный геометрический гротеск с плотными кириллическими буквами. Нельзя использовать рукописные, узкие, засечковые или «технологические» шрифты.

| Роль | Размер на 2896 px | Начертание | Интерлиньяж | Правило |
|---|---:|---:|---:|---|
| Главный заголовок | `170-196 px` | 700 | `0.96-1.02` | До 2 строк, выравнивание по центру |
| Число в метрике | `248-300 px` | 700 | `0.9` | Только крупное, без лишних знаков |
| Название карточки | `66-80 px` | 700 | `1.05` | До 2 строк |
| Подзаголовок/результат | `64-76 px` | 700 | `1.05` | Например, «Было», «Стало» |
| Нижняя поясняющая строка | `48-56 px` | 400-500 | `1.2` | Одна короткая мысль |
| Текст на иконке | `44-54 px` | 600-700 | `1.1` | Не более 2-3 слов |

Не уменьшать текст до нечитаемого размера ради добавления подробностей. Если мысль не помещается, сделать вторую инфографику.

## 5. Конструктор композиции

### Тип A - «Направления»

Использовать, когда нужно разделить услуги, сегменты, товары или типы спроса.

- Верх - главный заголовок.
- Центр - сетка из 2 или 4 белых карточек.
- В каждой карточке - одна крупная предметная 3D-иконка и короткое название.
- Низ - тонкие оранжевые линии слева и справа от одной выводящей фразы.
- Нельзя смешивать в одной карточке более одного объекта или двух смыслов.

Пример структуры: `вывески / буквы / короба / конструкции`.

### Тип B - «Цепочка»

Использовать для воронки, пути пользователя, последовательности этапов и передачи данных.

- Верх - главный заголовок.
- Центр - 3-5 одинаковых вертикальных карточек в одну строку.
- Между карточками - простые оранжевые стрелки вправо.
- Внутри - один объект, его название и минимум подписи.
- Низ - вывод в формате «Пользователь видит нужное сразу».

Пример структуры: `Запрос → Услуга → Портфолио → Расчёт`.

### Тип C - «Было/Стало»

Использовать для кейса, CPL, выручки, конверсии, срока или доли целевых заявок.

- Верх - крупный заголовок «Кейс: ...».
- Центр - две одинаковые белые карточки с большим числом.
- Между ними - оранжевая стрелка.
- Левое число - графитовое, правое - оранжевое.
- Под цифрами обязательно дать смысл: «Было» и «Стало».
- Внизу - название ниши и короткий вывод.

### Тип D - «Один принцип»

Использовать для объяснения одной механики: аналитика, оффер, сегментация, ретаргетинг.

- Один центральный 3D-объект или одна крупная карточка.
- Вокруг - максимум 3 подписи/связи.
- Заголовок занимает верхнюю четверть холста.
- Не превращать такой тип в диаграмму с множеством стрелок.

## 6. Карточки, стрелки и разделители

### Карточки

- Фон `#FFFFFF`.
- Скругление `56 px`.
- Тень мягкая, направленная вниз, без серого контура.
- Внутренний отступ `52-64 px`.
- Карточки одинакового типа должны иметь одинаковые размеры.
- Белая карточка не должна быть прозрачной, стеклянной или цветной.

### Стрелки

- Цвет `#FF6A00`.
- Толщина `18-24 px` для крупной стрелки между карточками.
- Прямая геометрическая форма, без градиентов, обводки и двойного контура.
- Стрелка показывает направление только в цепочке или сравнении. Не использовать её как декоративный элемент.

### Нижний разделитель

- По одной тонкой оранжевой линии с обеих сторон от вывода.
- Толщина `6 px`, длина около `210 px` при холсте 2896 px.
- Центральная фраза графитовая, без капслока и не более 7 слов.

## 7. Язык 3D-иконок

Объекты выглядят как аккуратные предметные миниатюры для бизнес-инфографики: глянцевый пластик, матовый металл, белый акрил, темный графит и оранжевая деталь.

Разрешено:

- 3D-буквы, вывески, экраны, лупа, окно сайта, портфолио, калькулятор, график, папка, телефон, коробка, схема, метрика;
- лёгкая перспектива 3/4;
- заметная, но мягкая тень под объектом;
- графитовые боковые грани, оранжевые акцентные поверхности;
- объекты без брендов, интерфейсных логотипов и читаемого мелкого текста.

Запрещено:

- люди, руки, лица, стоковые фотографии;
- эмодзи и стандартные плоские иконки;
- неон, стекло, хром, кислотные блики, объёмные градиенты;
- случайные абстрактные фигуры;
- изображения экранов с нечитаемым псевдотекстом;
- более одного акцентного оранжевого объекта в карточке.

Для интерфейсной иконки на экране вместо мелкого текста использовать простые блоки: прямоугольник, три короткие линии, сетка из четырёх квадратов, крупная кнопка.

## 8. Правила содержания

1. Одна картинка отвечает на один вопрос из статьи.
2. Заголовок должен повторять смысл ближайшего H2, но не обязательно дословно.
3. Каждая карточка содержит только одну сущность и одно короткое название.
4. Цифры нужны только в кейсах и должны совпадать с текстом статьи.
5. Не дублировать абзац статьи в изображении.
6. Не обещать результат и не использовать маркетинговые слова без данных: «лучший», «гарантия», «100%».
7. Фраза внизу - вывод, а не CTA.
8. Перед генерацией утвердить текст всех надписей - они должны быть короткими и без ошибок.

## 9. Шаблон промта для генерации

Использовать этот промт как основу. Заменять только поля в квадратных скобках.

```text
Создай русскоязычную бизнес-инфографику для статьи на белом фоне #FAFAF8,
горизонтальный холст 4:3, 2896x2172. Стиль: чистая премиальная редакционная
инфографика, крупная графитовая типографика #171B20, один оранжевый акцент
#FF6A00, белые карточки с очень мягкими тенями, аккуратные предметные 3D-иконки
из матового пластика и графитового металла. Используй шрифт, близкий к TT Masters:
плотный геометрический гротеск с читаемой кириллицей.

Композиция: [ТИП КОМПОЗИЦИИ].
Главный заголовок сверху по центру: «[ЗАГОЛОВОК]».
Карточки и подписи: [КАРТОЧКИ И КОРОТКИЕ ПОДПИСИ].
Нижний вывод: «[ВЫВОД]», по бокам от него две тонкие оранжевые линии.

Требования: не использовать людей, фотографии, логотипы, эмодзи, градиенты,
неон, лишние декоративные элементы, мелкий текст, нечитаемые символы или
английские надписи. Все русские слова должны быть написаны без ошибок.
Оставь много чистого белого пространства. Оранжевый цвет использовать только
для стрелок, ключевого числа и небольших деталей иконок.
```

### Промт для цепочки

```text
Тип композиции: цепочка из четырёх одинаковых белых вертикальных карточек.
Между карточками - большие простые оранжевые стрелки вправо.
Заголовок: «Как работает [ТЕМА]».
Карточки: «[ШАГ 1]», «[ШАГ 2]», «[ШАГ 3]», «[ШАГ 4]».
Для каждой карточки - одна крупная предметная 3D-иконка.
```

### Промт для кейса

```text
Тип композиции: сравнение «Было/Стало».
В центре две крупные белые карточки одинакового размера, между ними одна
оранжевая стрелка. В левой карточке графитовая цифра «[БЫЛО]» и подпись
«Было». В правой карточке оранжевая цифра «[СТАЛО]» и подпись «Стало».
Внизу: «[НИША]» и вывод «[РЕЗУЛЬТАТ]».
```

## 10. Экспорт и размещение на сайте

| Сценарий | Формат | Правило |
|---|---|---|
| Инфографика в статье | JPEG | Основной формат, без WebP-версии внутри текста |
| Обложка статьи/карточки | WebP | Отдельный файл, допустимо использовать ту же композицию |
| Размер | `2896 × 2172 px` | Не обрезать важные элементы |
| Сжатие JPEG | качество `88-92` | Сохранить резкость русского текста |
| Сжатие WebP | качество `82-88` | Проверить читаемость мелких деталей |
| Имена файлов | `01-тема.jpg`, `02-тема.jpg`, `03-кейс.jpg` | Латиница, дефисы, порядок по статье |

В HTML для каждой картинки обязательны естественный `alt`, точные `width` и `height`. Для изображений ниже первого экрана - `loading="lazy"`.

## 11. Финальная проверка перед публикацией

- [ ] Холст 4:3, фон почти белый.
- [ ] Один крупный заголовок, читаемый с первого взгляда.
- [ ] Использованы только графитовый, белый и оранжевый.
- [ ] Карточки белые, со скруглением и мягкой тенью.
- [ ] Все русские надписи вычитаны вручную.
- [ ] Никакого мелкого текста, логотипов, людей и псевдотекста.
- [ ] Одна иллюстрация передаёт одну мысль.
- [ ] Цифры и формулировки соответствуют тексту статьи.
- [ ] Для статьи экспортирован JPEG, для карточки - WebP.
- [ ] На мобильном превью остаются читаемыми заголовок, ключевые цифры и подписи.
