# Система аналитики SEO naklikay.ru

Обновлено: 2026-11-25

## Цель

Главный результат системы - увеличивать число страниц сайта в ТОП-5 и ТОП-3 Яндекса. Упоминания и ссылки в ответах Алисы, ChatGPT и других нейросетей отслеживаются отдельно и не смешиваются с органическими позициями.

## Источники

| Источник | Что используем | Режим |
|---|---|---|
| Яндекс Вебмастер | URL, запросы, показы, клики, CTR, позиции, индексация, диагностика | Основной ежедневный сбор |
| Topvisor | Контрольные позиции в Яндексе по единому набору запросов, региону и устройству | Съём раз в 14 дней |
| Яндекс Метрика | Органические визиты, просмотры, глубина, время просмотра, отказы, переходы в мессенджер | Еженедельный сбор |
| Журнал усилений | Что изменили, URL, дата, базовые показатели, дата контроля и результат | Запись после каждого изменения |
| AI-наблюдения | Запрос, модель, наличие упоминания, URL-источник и дата проверки | Только по подтверждённой ручной или сервисной проверке |
| Bing | Отдельные экспериментальные данные | Не смешивать с Яндексом |

Google Search Console не входит в основной контур продвижения домена .ru.

## Связка наблюдений

Лист «История страниц» хранит один снимок URL на каждую дату данных. Каждая запись содержит текущий и предыдущий период, источник, статус наличия данных и найденную последнюю запись из «Журнала усилений». Пустые данные не считаются нулевыми.

Лист «История Метрики» хранит еженедельные снимки по URL. В нём отдельно фиксируются переходы в мессенджер по цели 581021196 «Автоцель: переход в мессенджер». Звонки и сообщения, которые не прошли через отслеживаемую цель, в данных не считаются подтверждёнными лидами.

## Правило работы со страницей

1. До изменения фиксируется базовый период в «Журнале усилений».
2. В журнал заносится фактически выполненное изменение, URL, дата, целевой интент и запросы.
3. После публикации страница отправляется на переобход Яндекса.
4. Ежедневный сбор записывает новые наблюдения автоматически.
5. Topvisor проверяет позиции раз в 14 дней.
6. Итог оценивается после полного контрольного окна, обычно через 28 дней, с учётом индексации, показов, кликов, позиций и данных Метрики.

## Решения

- «Доработать» - есть подтверждённый потенциал и страница не находится в целевом ТОП-5.
- «Наблюдать» - данных мало, период после изменения ещё не завершён или источник временно неполный.
- «Не трогать» - страница уже в целевой зоне и не имеет подтверждённой технической или интентной проблемы.
- «Проверить» - есть падение, пересечение URL, потеря индексации или несоответствие целевого запроса.

Topvisor используется как контроль выдачи и источник сигналов. Решение о переписывании принимается только после сверки с Яндекс Вебмастером, журналом изменений и Метрикой.

## Ограничения

Исторические данные Яндекса, которые не были переданы из-за недоступности PRO-выгрузки, задним числом не восстанавливаются. С 25 ноября 2026 года накопление наблюдений выполняется новым автоматическим снимком URL. Внешняя публикация Apps Script и изменение Google-таблицы в этой рабочей копии не выполняются автоматически.
