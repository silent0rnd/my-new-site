- Bing AI Performance: доступ, поля и экспорт не подтверждены.
- Webvisor: `script.js` подключает фронтенд-счётчик Яндекс Метрики 110564693 с

- Реальная SEO-карта интентов:
  `seo-project-sources-v8/naklikay_seo_intent_map_2026-10-26_MONITORING_EXISTING_PAGES.md`.
- Публикация и новые статьи: существующий навык `blog` (не менять).
- Аудит и оптимизация уже опубликованных URL: `seo-optimizer`.

## Неизменные правила

Не подменять наблюдения гипотезами. Не смешивать метрики разных поисковиков.
Не менять URL, canonical, redirects, robots и действующие скрипты без прямой
команды. Не считать архивный sitemap доказательством актуального состояния.
