# Изображения в статьях

- Внутри текста статей использовать исходные JPEG-изображения через тег `img`.
- Не добавлять WebP-источник в `picture` для схем, скриншотов и иллюстраций внутри статьи.
- WebP разрешен для плиток, карточек и других небольших превью в списке блога.
- Для изображений в статье сохранять `loading="lazy"`, если картинка не находится в первом экране.
