# Изображения в статьях

- Для новых иллюстраций использовать исходный PNG в пропорции 4:3, стандартный размер 2096 x 1572 px.
- PNG оптимизировать без потери качества. Не уменьшать исходник ниже 1720 px по ширине, чтобы сохранять запас для WebP-версии 1720 px.
- Для каждой иллюстрации создавать WebP 640, 1080 и 1720 px. В статье подключать их через picture и srcset, а PNG сохранять как запасной источник в img.
- Сохранять атрибуты width="2096" и height="1572" в img. Для первого экранного изображения не использовать loading="lazy", для остальных использовать loading="lazy" и decoding="async".
- Не перегенерировать WebP без прямой необходимости: изменение размера исходного PNG не требует повторного экспорта уже проверенных WebP-файлов.
