# Изображения в статьях

- Для новых иллюстраций использовать исходный PNG в пропорции 4:3, размер 2896 x 2172 px.
- PNG оптимизировать без потери качества. Правила подготовки, согласования, выбора превью и экспорта приведены в docs/04-instruktsiya-generatsii-illyustratsiy.md.
- Для каждой иллюстрации создавать WebP 640, 1080 и 1720 px. В статье подключать их через picture и srcset, а PNG сохранять как запасной источник в img.
- Сохранять атрибуты width="2896" и height="2172" в img. Для первого экранного изображения не использовать loading="lazy", для остальных использовать loading="lazy" и decoding="async".
- При замене рисунка заново экспортировать все три WebP из утверждённого исходника. При неизменном рисунке и готовых производных повторный экспорт не требуется.
